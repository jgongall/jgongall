## 🚀 Proyectos destacados

### 🤖 IA · Hotopia — plataforma de ficción interactiva con LLMs
Monorepo con arquitectura de microservicios orientada a IA:
- **Orquestador LLM** propio que arma el contexto, hace *streaming* SSE token a token y gestiona **memoria de largo plazo** extraída de las respuestas del modelo.
- **Servidor MCP** con herramientas (`get_story_context`, `remember_fact`, `save_turn`) consumidas por el orquestador.
- Modelos locales vía **Ollama / vLLM** (API OpenAI-compatible) con Modelfiles personalizados.
- API **FastAPI** con JWT, cuotas de tokens en **Redis**, **PostgreSQL** async (SQLAlchemy) y pagos con Mercado Pago.
- Frontend **Next.js 16 / React 19**; despliegue con **Docker Compose + Caddy**.

`Python` `FastAPI` `MCP` `Ollama` `SSE` `Redis` `PostgreSQL` `Next.js` `Docker`

### ✅ QA · [SeleniumDriverCucumber](https://github.com/jgongall/SeleniumDriverCucumber)
Framework de automatización UI con **Selenium WebDriver + Cucumber (BDD) + Java**: escenarios Gherkin legibles por negocio, Page Objects y step definitions reutilizables.

`Java` `Selenium` `Cucumber` `BDD` `Page Object Model`
